# ClassCore — Downloads

ClassCore is tuition and institute management software for Windows, with a companion app for Android phones. Students, batches, attendance, fees, exams, expenses, staff and WhatsApp messages in one place. It works without internet and syncs with the phone when online.

This page is for downloading the software. The source code is kept in a separate private repository.

| **ClassCore Mobile for Android** | 1.9.2 | [Download ClassCore-Mobile.apk](https://github.com/prajapatikuldeep455-source/classcore-releases/releases/latest/download/ClassCore-Mobile.apk) |

### Install on Windows
1. Download `ClassCore-Setup-x.y.z.exe` from the latest release.
2. Run it. If Windows shows *"Windows protected your PC"*, click **More info → Run anyway**.
3. Open ClassCore and follow the first-run setup.

### Install on an Android phone
1. Download `ClassCore-Mobile.apk` on the phone.
2. Open it. If asked, allow *Install unknown apps* for your browser or file manager.
3. **Owner:** sign in with your ClassCore username and password, or with Google.
   **Teacher or staff:** tap **Join with QR from PC** and scan the code the owner shows in *ClassCore PC → Settings → Staff & Roles → Connect phone*.

### Updates
- **Windows:** ClassCore checks for updates by itself and shows *What's new* after updating. If an update ever fails, download the latest setup from this page and run it over the old version. Your data stays.
- **Android:** the app tells you when a new version is available. You can also download the APK from this page and install it over the old one.

## What's new

### Windows 3.6.1 · Android 1.9.2
- **Staff phones with a QR code.** Every teacher or staff member gets their own phone app with only the rights the owner gives them. No password to share: they scan a one-time QR code from the PC. One phone per person, and everyone can use the app at the same time.
- **Owner's own phone.** *Connect my phone* on the owner's card asks for the owner's PC password first.
- **Remove a phone in one click.** Remove the phone, or mark the employee *Inactive*. Their phone signs out at once and its ClassCore data is cleared.
- **WhatsApp through the PC.** Receipts, report cards and notices from a connected phone go out from the WhatsApp linked on the PC, with the PDF. Messages sent while the PC is closed go out when it opens.
- **Phone app:** new line icons in place of emoji, WhatsApp button opens the WhatsApp app directly, clearer sending status.

### Windows 3.5.8
- Calendar with Indian festivals and government holidays (2026–2027, all India and Gujarat), birthdays, exams, institute holidays, tasks and reminders.
- *Today's to-do* on the dashboard, Ctrl+K student search, first-run setup, date of birth.
- Attendance: remove a wrong mark, undo, history, lock old days.
- Daily automatic backups and exact fee totals.

Full notes for every version are on the [Releases](https://github.com/prajapatikuldeep455-source/classcore-releases/releases) page.

## Features

| Area | What it does |
|---|---|
| Students | Admission form, photo, guardian details, batches, Excel import and export, full student profile |
| Attendance | Daily register by batch, QR attendance on the phone, biometric machines (eSSL, Realtime, ZKTeco, Mantra), absent alerts to parents |
| Fees | Monthly, yearly or instalment plans, receipts from A4 to 58/80 mm thermal, UPI QR on receipts, fee card printing, dues list |
| Exams | Marks, report cards, question paper generator with GSEB and NCERT chapters |
| Money | Expenses, staff salaries, monthly reports and Excel export |
| WhatsApp | Built-in WhatsApp Hub: receipts, reminders, broadcasts, auto-reply |
| Staff | Roles and rights per employee, staff phones by QR code |
| Calendar | Festivals, holidays, birthdays, exams, tasks with reminders |
| Backup | Daily backups on the PC, manual snapshots, restore |
